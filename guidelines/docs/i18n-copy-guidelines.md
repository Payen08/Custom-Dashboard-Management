# 多语言文案规则

## 文案版本

- 标准版用于页面标题、模块名称、表单字段、弹窗标题和说明文案，必须完整表达业务含义。
- 简短版用于导航、Tab、Tag、按钮、卡片入口和表格表头。上下文已经明确时，不重复对象或父级含义。
- 当标准版超出可用空间时，才使用对应的简短版；不可通过截断标准版制造新的简称。
- 父级已经表达“管理”等含义时，子级删除重复的 `Management` 等冗余词。
- 简短版不得删除用于区分业务模块的核心名词。删除后无法唯一识别模块时，简短版必须与标准版相同。例如“型号模板”不能缩为“模板”，“软件产品”不能缩为“软件”，“字段字典”不能缩为“字典”。
- 左侧业务导航按语言处理：简体中文和繁体中文显示完整业务名称，不使用简短版；英文、马来语和越南语使用导航简短版以适配宽度。

## 全局操作词

所有页面必须复用 `src/app/i18n.tsx` 中的 `GLOBAL_ACTION_COPY`，不可在页面内为同一操作另造译法。

| 中文 | English | 用途 |
| --- | --- | --- |
| 新增 | Create | 创建新的业务对象 |
| 添加 | Add | 向已有对象或集合添加内容 |
| 编辑 | Edit | 修改已有对象 |
| 删除 | Delete | 删除对象或记录 |
| 移除 | Remove | 解除关联或从集合移出，不等同于删除源对象 |
| 保存 | Save | 保存当前修改 |
| 刷新 | Refresh | 重新加载当前数据 |
| 搜索 | Search | 搜索入口、按钮及占位符 |
| 重置 | Reset | 恢复筛选或配置初始状态 |
| 导入 | Import | 导入文件或数据 |
| 导出 | Export | 导出文件或数据 |

## 确认弹窗

- 弹窗标题简短，例如“删除软件产品”。
- 正文使用完整疑问句，例如“确定要删除软件产品「控制器驱动」吗？删除后无法恢复。”
- 按钮只使用简短操作词，例如“取消 / 删除”，禁止使用“确认删除”。

## 示例

- 页面标题：`Software Product Management`；导航：`Software`。
- 弹窗标题：`Create Software Product`；按钮：`Create`。
- 模块标题已写明 `Meshes` 时，右侧按钮使用 `Add`；无明确上下文时使用 `Add Mesh`。
