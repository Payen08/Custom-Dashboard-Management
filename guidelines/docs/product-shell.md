# 数字造机产品外壳规范

本文件定义所有数字造机及其同级业务系统必须复用的产品外壳。业务页面只负责主内容，不得重新设计全局导航、顶栏、主题切换或页面滚动关系。

## 1. 固定结构

```text
ProductShell
├── ProductNavigation：产品标识、一级模块、返回工作台、当前用户
└── ProductMain
    ├── GlobalTopBar：侧栏、全局搜索、主题、刷新、通知
    └── PageViewport：唯一页面承载区
```

| 区域 | Current 桌面规格 | 规则 |
| --- | --- | --- |
| ProductNavigation | 宽 200px；左右内边距 16px | 固定左侧，不随页面内容滚动。 |
| GlobalTopBar | 高 52px；左右内边距 24px | 固定顶部；业务页面不得追加第二条全局顶栏。 |
| 一级导航项 | 高 48px；圆角 12px；图标 18px | 项间距 8px；文字 14px；当前项字重 600。 |
| 当前导航项 | `accentSoft` 背景、`accent` 文字 | 左侧显示 3px 指示条；Hover 不覆盖 Selected。 |
| 产品标识 | 34px 品牌底图标＋产品名＋10px 说明 | 点击按产品定义返回首页或工作台，不作为普通导航项。 |
| 顶栏图标按钮 | 32px 鼠标热区；图标 16px | 必须提供 `aria-label` 与 Tooltip。 |
| PageViewport | 占满剩余宽高 | 页面模板决定内部滚动；`body` 不承担业务滚动。 |

## 2. 导航内容

- 一级导航只放跨页面模块，不放行内操作、筛选或当前对象动作。
- 当前页面使用持续 Selected 状态，不使用 Hover、Pressed 或临时高亮代替。
- 导航底部保留返回墨影工作台和当前用户信息；业务系统不得删除安全返回路径。
- 导航图标使用已批准的线性系统图标，图标和文字共同构成点击热区。
- 产品名可按业务替换，例如“数字造机”“智能制造”；布局、尺寸与交互保持一致。

## 3. 顶栏内容

- 左侧为侧栏控制；右侧依次为全局搜索、主题切换、刷新和通知。
- 页面级搜索属于页面 Toolbar，不得与顶栏全局搜索共用状态或替代彼此。
- Current 模式不得展示工业主题色选择器。风格预设入口只在产品明确开放时出现。
- 顶栏与导航使用 `surface` 背景和 `border` 分隔，不增加场景化渐变、纹理或装饰阴影。

## 4. 响应式与滚动

- 1200px 及以上保持 200px 导航和完整文字。
- 768–1199px 可收敛次要顶栏操作，但导航尺寸与热区不小于已发布规格。
- 767px 及以下可将导航收起为抽屉或 64px 图标栏；所有图标仍需 Tooltip 和可访问名称。
- ProductNavigation 与 GlobalTopBar 固定；PageViewport 内只能有一个页面主滚动容器。
- 表格、树、日志、画布可拥有局部滚动，但不得使 ProductShell 或 `body` 横向滚动。

## 5. 验收

- 与数字造机参考页面的导航宽度、顶栏高度、选中态和操作顺序一致。
- Light/Dark 下均只使用语义 Token，不存在页面私有硬编码主题色。
- 键盘可进入所有导航和顶栏操作，Focus Ring 不被裁切。
- 页面切换时外壳稳定，只有 PageViewport 内容变化。
