
  # Custom Dashboard Management

  This is a code bundle for Custom Dashboard Management. The original project is available at https://www.figma.com/design/yK3lKc8xy7u63ZEr2xIoZt/Custom-Dashboard-Management.

  ## Live demo

  Deployed on GitHub Pages: https://payen08.github.io/Custom-Dashboard-Management/

  The site is automatically rebuilt and deployed on every push to `main` via the [GitHub Actions workflow](.github/workflows/deploy.yml).

  ## Running the code

  Run `npm i --legacy-peer-deps` to install the dependencies.

  Run `npm run dev` to start the development server.

  Run `npm run build` to produce a production build in `dist/`.

  ## Design system

  The standalone GitLab-ready design-system handoff is in [`guidelines/`](guidelines/README.md).
  Runtime prototype styles remain in `src/styles/` and are not the frontend handoff source.
